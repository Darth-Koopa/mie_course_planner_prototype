MIE MEng Course Planning Workspace — Prototype v5

Change in v5:
- Financial Engineering course lists are treated as certificate requirement references, not as current-term course offerings.
- Financial Engineering requirement courses without supplied term-specific offering data are hidden from Section 2 (Course Explorer), including when the Financial Engineering certificate filter is selected.
- Courses with independently supplied offering data remain in Course Explorer (for example APS502, MIE1620 and MIE1624).
- All Financial Engineering requirement options remain visible in the collapsible certificate requirement panel in Course Plan Overview.
- Requirement-list courses remain searchable from the Plan Overview quick-add field so users can record prior coursework or tentative plans. Their offering status remains unverified unless term data is supplied.

To use:
1. Extract the ZIP file.
2. Open mie_course_planner_prototype_v5.html in Chrome or Edge.

Data notice:
This is a demonstration prototype. It does not connect to ACORN or U of T databases. Course offering details and requirement calculations are illustrative and must be verified with official sources.
